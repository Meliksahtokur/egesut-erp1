## Key Findings

### Why SQLite First?

1. **Performance**: 10-100x faster queries
2. **Full-text Search**: Native FTS5 with BM25 ranking
3. **Scalability**: Supports millions of notes without degradation
4. **Reliability**: WAL mode + ACID transactions
5. **Compatibility**: Lightweight, no server needed

### FTS5 Advantages

- **BM25 Ranking**: Industry-standard relevance scoring
- **Trigram Tokenization**: Better for partial matching
- **Highlight Support**: Direct `<mark>` tag injection
- **Phrase Search**: "exact phrase" support
- **Ranking**: `bm25(notes_fts)` for relevance ordering
