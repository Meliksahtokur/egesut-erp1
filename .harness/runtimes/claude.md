# Claude Runtime Adapter

Shared policy: `../contract.md`

Claude Code discovers `CLAUDE.md`, which imports `@AGENTS.md` and points to
this adapter for runtime-only guidance.

- Prefer inline or Claude built-in agents unless the owner selects another
  flow.
- Do not infer an active external worker system from legacy documentation.
- Root/lead remains responsible for manifest control and acceptance.

This adapter does not define product, Git, database, or acceptance policy.
