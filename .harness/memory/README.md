# Harness Memory Boundary

This directory is reserved for small, curated, evidence-backed lessons that
prevent a future wrong decision and are not already represented by a goal,
report, decision, contract, or commit.

Do not store progress narration, raw transcripts, terminal output, worker
self-reports, runtime state, credentials, or generated indexes here. Workers do
not write canonical memory. Leads require explicit goal authority; otherwise
they submit a candidate in their report for root adjudication.

`MEMORY-INDEX.md` is generated to stdout or ignored `.harness/cache/`. It is not
tracked and does not become an independent source of truth.
