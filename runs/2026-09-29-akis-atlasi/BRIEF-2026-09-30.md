## 2. Ana tez: trace-first (kanıt-önce)

- "Agent inference ≠ evidence. LLM 'bu buton şu RPC'yi çağırıyor' diyebilir; atlas ancak
  trace/HAR/static edge veya DB evidence ile CONFIRMED olmalı" [PART-01:15].
- "Keşif LLM'ye bırakılabilir; kanıt bırakılamaz" [SENTEZ:38]. "LLM agent **explorer**,
  Playwright recorder **witness** olmalıdır" [PART-02:45].
- Tek araç bütün zinciri çıkarmıyor; "flow atlas bir **evidence fusion** problemidir" [PART-01:28].
- Önerilen 4 katman: (1) keşif = Playwright Test Agents + Playwright MCP, (2) runtime kanıt =
  trace + HAR + dialog kaydı + IndexedDB diff, (3) derin teşhis = Chrome DevTools MCP,
  (4) backend = plpgsql_check + pg_trigger + cron.job; GitNexus statik katman olarak korunur
  [README:7-14, SENTEZ:19-34].
- Kanonik veri `flow.json`/`flow.yaml` + evidence dosyaları; Markdown/Mermaid TÜREMİŞ render;
  her düğümde `last_verified_commit`, `source_globs`, `evidence_refs` [SENTEZ:13, 43-78, PART-07:11-26].
- Net karar: "Önce yeni bir crawler framework kurma. Mevcut Playwright yatırımını
  'evidence recorder + atlas emitter' seviyesine çıkar" [SENTEZ:139]. Senaryo A (Trace-first)
  varsayılan; Crawljax (son release 2023) yalnız 2-4 saatlik PoC/benchmark adayı [SENTEZ:84, PART-02:21].

- G2 kabul ölçümü: gerçek geçmiş kaçaklardan türetilmiş soru seti ("GEBELIK_KONTROL'ü kim üretir?",
  "bu tıklama hangi confirm()'dan geçer?"); AYNI ajan, AYNI sorular, kademeli girdi:
  (a) yalnız kod + GitNexus → (b) + kanıt JSON → (c) + LLM mantık anlatımı → (d) + PNG/çizim.

- G1'deki LLM mantık anlatımı/PNG katmanları yalnız ölçümle geçenlerin atlasa girmesine bağlı [SAHIP-G:14].
