Mockup 7 — Boş sonrası devam akış diyagramı
🧭 "Boş" sonrası devam — uçtan uca akış
Devam seçici → 3 dal (Ovsync / PG / Takibe bırak) → takip DB'de otomatik kapanır ya da muayene görevine düşer → döngü

🐄 Tohumlama sonucu: Boş

Sonuç modalında "❌ Boş" seçilir

↓

🧭 Devam seçici (zorunlu)

Ovsync uygula / PG uygula / Takibe bırak — biri seçilmeden Kaydet pasif. Hepsi tek işlemde yapılır.

↓
seçime göre 3 dal

🔄 Ovsync

Vaka bugün açılır (4 uygulama + TAI) → hayvan Ovsync Takip ekranı ② Aktif zincirler'e düşer

💉 PG

+48 saat TAI görevi açılır (uygunsa) — ürün/doz seçici önceden dolu

🔍 Takibe bırak

Varsayılan +7 gün, şu anki saat → rektal muayene görevi açılır

↓ takip açıkken

⏳ Takip açık — DB otomatik kapatır

  • yeni tohumlama kaydı → sessiz kapanış
  • Ovsync / PG başlatma → onay penceresi ("Bu hayvan takipte") → kapanış
  • hayvan çıkışı (satış/ölüm) → kapanış
↓ takip kapanmadan muayene günü gelirse

🔍 Muayene görevi → muayene sonucu ekranı

"🔍 Takip muayenesi — Küpe X" ekranı açılır

↓

🧭 Yine devam seçici

Ovsync uygula / PG uygula / 📅 Muayeneyi ertele (↺ +7 gün) / 🐄 Kızgınlıkta → tohumlama kaydına geç

↺ "Muayeneyi ertele" seçilirse aynı Devam seçici kutusuna döner
Kural notu: Kısır / kural günü gelmemiş → Ovsync kilitli (hard block), 🔒 gerekçeli.
Kural notu: Takip açıkken otomatik Ovsync görevi açılmaz — takip kapanmadan yeni zincir başlamaz.
