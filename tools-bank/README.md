## 🚀 **Quick Start Any Component**

```bash
# Clone the bank
git clone https://github.com/yourusername/brainstorm.git
cd brainstorm

# Use memory intelligence
cd memory && python3 search_tool.py --query "your_search"

# Spawn an agent
cd agents && mini-agent --config erp-config.json --task "analyze_codebase"

# Load a skill
cd skills && /skill memory-intelligence

# Run a tool
cd tools && python3 health_monitor.py

# Check examples
cd examples && cat erp-automation-example.md
```
